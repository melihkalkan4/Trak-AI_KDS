## 1. KRITIK BAŞARIMLAR

### 1.1 Firmware Sıfırdan Refactor

**Önce:** main.cpp ~1100 satır, fonksiyonlar birbirine girmiş, ArduinoJson v6.

**Sonra:** main.cpp ~750 satır, fonksiyon grupları net (Motor, Sensor, MQTT, NAV,
OTA, Telnet, SPIFFS), ArduinoJson v7. config.h tek kaynak temizliği.

**Sonuç:** 350 satır azalma + bakımı çok kolay yapı. Build 883KB, RAM 15.2%.

### 1.2 DB Bug — VIEW → TABLE Migration

**Önce:** `rover_olcumler` SQLite VIEW idi → INSERT'ler sessizce başarısız oluyordu.
Şimdiye kadar **0 satır rover verisi DB'ye kaydolmamış**.

**Sonra:** VIEW drop'landı, gerçek TABLE oluşturuldu (rover_id + engel_arka_cm
kolonları dahil). Migration idempotent — eski DB'lerde çalışır.

**Test sonucu:** 3 satır manuel INSERT başarılı, rover_id ile filtreleniyor.

### 1.3 SEN0193 Ters Sensör Keşfi

**Önce:** Toprak nem sensörü havada %98 gösteriyordu — anormal.

**Tanı:** Telnet üzerinden ham ADC izleme. raw=161 (kuru) → raw=688 (su).
Sensör **ters çıkışlı klon** — düşük voltaj = kuru, yüksek voltaj = ıslak.
Standart SEN0193'ün tersi.

**Çözüm:** `adcToNem()` fonksiyonuna auto-detect mantığı eklendi
(SOIL_DRY_RAW < SOIL_WET_RAW → ters formül). Kalibrasyon swap: DRY=200, WET=750.

**Doğrulama:**
| Test | Beklenen | Ölçülen |
|---|---|---|
| Havada (kuru) | %0-5 | **%1.5** ✓ |
| El temas | %5-15 | **%7.3** ✓ |
| Yarı ıslak | %50-70 | **%66.0** ✓ |

### 1.4 OTA WiFi Update + Telnet

Hem firmware update hem live debug **USB kablo gereksinin pas geçildi**:
- **OTA upload:** 49-74 saniye, mDNS hostname + auth password
- **Telnet remote serial:** Port 23, PowerShell TcpClient ile USB-less monitor

**Get-NetTCPConnection kanıt:**
```
LocalAddress   RemoteAddress  RemotePort  State
192.168.1.107  192.168.1.106          23  Established
```
